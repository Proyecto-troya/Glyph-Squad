Leaf Plate: prototipo de interfaz

Cada marco es la app a 375 px de ancho, con el DOM que arman las pantallas de app/src/ui/ y la hoja de estilos propuesta style.css (marca "Ver la hoja original" para comparar con la actual). Todo se puede tocar: la cámara devuelve resultados de ejemplo, Sí / No responde y las pestañas navegan.
